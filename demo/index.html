Text Interface Demos

A beginner-friendly JavaScript library for interactive text-based programs in the browser.

About the Library

The Text Interface library gives you a simple way to create interactive, terminal-style programs right in the browser. It is perfect for beginning programmers learning JavaScript—you can read input, display output, and build text-based games without worrying about HTML or complex UI. 

import { TextInterface } from "text-interface";

const ti = new TextInterface();
await ti.output("What is your name?");
let name = await ti.readText();
await ti.output("Hello, " + name + "!");

Getting Started

Install the library with npm:

npm install text-interface

Or add a script tag to any HTML page:

<script type="module">
  import { TextInterface } from
    "https://cdn.jsdelivr.net/npm/text-interface@latest/dist/text-interface.es.js";
  const ti = new TextInterface();
  let name = await ti.prompt("What is your name?");
  await ti.output("Hello, " + name + "!");
</script>

Themes & Customization

The library ships with 14 built-in themes you can swap at runtime. Each demo above uses a different theme. You can also create your own by setting CSS custom properties. 

import { applyTheme, themes } from "text-interface";
applyTheme(themes.dracula);   // or greenTerminal, typewriter, nord…
